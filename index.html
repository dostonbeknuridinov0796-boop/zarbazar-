🔥 Подключение Firebase

Firebase — бесплатная база данных от Google. После подключения все данные (заказы, акции, фото, настройки) будут синхронизироваться между всеми устройствами в реальном времени.

📋 Как получить конфиг Firebase

1️⃣ Зайди на firebase.google.com
2️⃣ Нажми «Go to console»
3️⃣ Нажми «Add project» → введи название
4️⃣ После создания нажми значок «</>» (Web)
5️⃣ Зарегистрируй приложение → скопируй конфиг
6️⃣ Иди в Realtime Database → Create database
7️⃣ Выбери регион → Start in test mode
8️⃣ Скопируй Database URL и вставь выше
